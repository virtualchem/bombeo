# bombeo
Calculo de las Perdidas para la selección de equipos de Bombeo
Información requerida:
  Caudal a bombear, 
  Diametro de la tubería
  Longitud de la tubería
  la cota del espejo del agua,
  la cota del sitio de descarga.

Calcula el total de perdidas en metros
Sugiere los HP que se requieren para realizar el bombeo.
